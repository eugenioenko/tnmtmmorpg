# smoke

Client-only ambience: smoke curls from cottage chimneys, campfires and the oven; the forge belches soot and sparks; the cauldron steams green; planted torches trail a wisp; fresh lightning scars steam.

Every source is read from entities already on screen (by kind, or a cottage door's frame), so other features need no changes. Plumes lean with the wind from `weather:here` and thin out in the rain.
