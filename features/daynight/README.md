# daynight

The time of day. One game hour passes every two real minutes, so a full day takes 48 minutes; time is derived from the wall clock, so it survives restarts and needs no storage. Outdoors the screen darkens through dusk (18:00–21:00, with a warm glow) into night and lightens again at dawn (04:00–07:00); caves and interiors are unaffected. A small clock in the right-hand column shows the hour and part of day. Other features follow the time through `daynight:hour { hour, day }`, emitted on the first tick and whenever the hour turns (the town's residents keep their daily routines by it); each player carries a private `daynight:time { minute, day }` updated every ten game minutes. Set `DAYNIGHT_SHIFT_HOURS` on the server to move the clock (handy for previewing night locally).
