# chat

Players talking to each other. Press Enter (or `/`) to open the chat bar; plain text is said aloud to everyone within 20 tiles and floats over your head as a speech bubble. Slash commands pick other channels: `/y` yells twice as far, `/g` reaches everyone online, `/w Name text` whispers and `R` (or `/r`) replies, `/me text` and fifteen built-in emotes (`/wave`, `/bow`, `/dance`, …) narrate, `/roll [max]` rolls dice in public, `/who` lists who is online, `/help` lists it all. The channel badge on the bar is sticky and can be clicked to cycle. Messages are delivered through each player's `chat:inbox`, a **private component**: the snapshot only sends it to its owner, so whispers never reach a bystander's client. Speech bubbles ride the public `chat:bubble` component. Sending is rate-limited to six lines per four seconds.
